## 测试的板子 (9 个)

### 9 人局 (6 个板子)

1. **9-standard** - 9 人标准局
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 3 村民
   - 特性: 无特殊功能
   - 胜利条件: 标准（屠神/屠民）

2. **9-guard** - 9 人守卫变体
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 守卫 + 2 村民
   - 特性: 包含守卫保护阶段
   - 胜利条件: 标准

3. **9-idiot** - 9 人白痴变体
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 白痴 + 2 村民
   - 特性: 白痴首次被投出局翻牌不死
   - 胜利条件: 标准

4. **9-knight** - 9 人骑士变体
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 骑士 + 2 村民
   - 特性: 骑士可决斗翻牌
   - 胜利条件: 标准

5. **9-cupid** - 9 人丘比特变体
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 丘比特 + 2 村民
   - 特性: 情侣跨阵营独立获胜 (`loversCrossWin: true`)
   - 胜利条件: 包含情侣独立获胜条件
   - 阶段: 包含 `CUPID_LINK` 阶段

6. **9-slaughter** - 9 人屠边局
   - 角色: 3 狼 + 预言家 + 女巫 + 猎人 + 3 村民（与标准局相同）
   - 特性: 无特殊功能
   - 胜利条件: 屠边（狼人杀光神或民任一方即胜利）

### 12 人局 (3 个板子)

7. **12-full** - 12 人完整神局
   - 角色: 4 狼 + 预言家 + 女巫 + 猎人 + 守卫 + 白痴 + 3 村民
   - 特性: 包含所有主要神职
   - 胜利条件: 标准

8. **12-swhi** - 12 人预女猎白
   - 角色: 4 狼 + 预言家 + 女巫 + 猎人 + 白痴 + 4 村民
   - 特性: 无守卫，更多村民
   - 胜利条件: 标准

9. **12-sheriff** - 12 人警长局
   - 角色: 4 狼 + 预言家 + 女巫 + 猎人 + 守卫 + 白痴 + 3 村民（与 12-full 相同）
   - 特性: 警长系统 (`sheriff: true`)，1.5 票权重，警徽传递
   - 胜利条件: 标准
